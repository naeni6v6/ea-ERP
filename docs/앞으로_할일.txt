 모션브릿지 ERP — 앞으로 해야 할 일
 (설계 지침 대비 미구현 항목 정리 / 작성일 2026-08-26)
================================================================

이미 완료된 것 (참고):
로그인·권한(Role×Scope), 사업유형/부서 관리, 프로젝트+업무+진행률,
거래 템플릿 등록(부가세 분리), 은행거래 CSV import+분류 큐, 경영유보금,
지급예정자금, 가용현금, 손익계산서(전년비교)+사업/부서/프로젝트/계정 분해,
대시보드, 전역 필터, 감사로그 기본, 좌측 사이드바, 유형별/사업부서별/기간별 카드 페이지


■ 1순위 — 바로 다음에 할 것 (MVP1 마무리 + 실사용 준비)
----------------------------------------------------------------
* 대시보드 숫자 Drill Down 해야됨 — KPI 클릭 → 사업별 → 부서별 → 프로젝트별 → 계정과목별 → 개별 거래까지 내려가기 (지침 24·36번)
* 비밀번호 변경 화면 해야됨 — 초기 계정(changeme123!)을 지금도 그대로 쓰는 중
* 거래처(Partner) 관리 화면 해야됨 — 지금은 API만 있고 화면 없음
* 계정과목 관리 화면 해야됨 — 계정 추가/수정을 화면에서 못 함
* 프로젝트 수정 폼 해야됨 — 생성은 되는데 수정 UI가 없음
* 거래 목록 페이지네이션 해야됨 — 거래 쌓이면 목록이 무한정 길어짐
* 대시보드 차트 해야됨 — 매출/이익 월별 추이 그래프 (지금은 숫자 카드만)
* 모바일 화면 점검 해야됨 — 대표가 폰에서 볼 핵심 KPI(오늘 입출금·잔액·가용현금·매출·영업이익) 레이아웃 (지침 46번)
* 실데이터 입력 시작해야됨 — 계좌 기초잔액(openingBalance) 입력 + 은행거래 CSV 가져오기부터


■ 2순위 — MVP2 (관리회계 심화, 지침 50번)
----------------------------------------------------------------
* 예산관리 해야됨 — 전사/사업/부서/프로젝트 단위 승인예산·사용액·집행예정·잔여예산·집행률, 예산 vs 실적 화면 (지침 32번, "예산 ≠ 현금" 구분 유지)
* 매출채권/미수금 건별(open item) 관리 해야됨 — 프로젝트별 "아직 받을 돈", 장기 미회수 표시 (지침 17번)
* 미지급금/매입채무 건별 관리 해야됨 — "앞으로 줄 돈"을 지급예정자금과 연결
* 계약부채 세션 관리 해야됨 — 라곰/DAP 회원권·PT: 총 결제금액/사용·잔여 세션/인식매출/잔여 계약부채 (지침 18·19번)
* 자산/부채 명세 해야됨 — 장비·차량·보증금·차입금 등 등록 + 프로젝트별 자산·부채 연결 (지침 16·20번)
* 선급비용 자동 상각 해야됨 — 1년치 임대료 선납 → 매월 자동으로 비용 인식하는 스케줄 (지침 15번)
* 현금예측 고도화 해야됨 — 입금예정까지 반영한 7/30/90일 예상잔액 (지금은 지급예정 차감만)
* 위험 알림 Rule Engine 해야됨 — 마감임박/업무완수율 저조/예산초과/원가율 급증/미수금 증가/가용현금 부족/프로젝트 예상적자 (지침 38번)
* 파일/증빙 첨부 해야됨 — 거래·프로젝트에 파일 업로드 (Attachment)
* 프로젝트 상세 탭 확장 해야됨 — "개요|재무|자금|업무|파일|활동기록" 구조로: 프로젝트별 채권/부채, 실제 입출금, 입금·지출 예정까지 (지침 33·45번)
* 업무 Weight 진행률 해야됨 — 데이터 구조는 있음(weight 필드), 계산·UI 활성화만 남음 (지침 9번)
* 급여의 프로젝트 배부 규칙 해야됨 — 현재 급여는 부서 판관비로만 처리 (설계결정 Q3에서 미뤄둔 것)
* 감사로그 화면 강화 해야됨 — 변경 전/후 비교를 보기 좋게, 필터/검색 추가 (지침 39번)


■ 3순위 — MVP3 (외부 연동, 지침 51번)
----------------------------------------------------------------
* 오픈뱅킹/은행 API 자동연동 해야됨 — Integration Layer는 이미 분리되어 있음, Provider 구현만 (지침 23번)
* 카드내역 연동 해야됨
* 세금계산서(국세청) 연동 해야됨
* 거래 자동분류 해야됨 — 규칙 기반 먼저, 이후 AI 분류
* 증빙 OCR 해야됨
