## 파일 규격

- **정사각형** PNG (예: 128×128). 원형으로 잘라 보여주므로 로고가 가운데 오도록 여백을 두세요.
- 배경 투명 또는 브랜드 배경색 둘 다 괜찮습니다.
- 카드사 로고는 각 사의 상표입니다. 공식 브랜드 가이드에서 받은 파일을 사용하세요.

발급사를 추가하려면 `apps/web/src/components/CardBrand.tsx` 의 `BRANDS` 목록에 한 줄 넣으면 됩니다.
